# Contributing to TripTrack

TripTrack is built by one developer, and the code is open so you can read how
it works, learn from it or fix something that bothers you.

- **Found a bug or have an idea?** Open an [issue](https://github.com/OneZee23/trip-track-ios/issues/new/choose).
  Please leave out trip coordinates, your home address and account e-mail —
  this repository is public.
- **Security or privacy problem?** Do not open an issue; see [SECURITY.md](SECURITY.md).
- **Want to send a change?** Open an issue first so we can agree on the
  approach, then a pull request against `master`. Setup steps are in the
  [README](README.md) (section «Локальная разработка»), and the project rules —
  units, localisation into 13 languages, dialogs, data model — are in
  [CLAUDE.md](CLAUDE.md). Every user-facing string goes through `AppStrings`.

The server and the website are separate, private projects; changes to the
sync protocol need both sides and are coordinated by the maintainer.
