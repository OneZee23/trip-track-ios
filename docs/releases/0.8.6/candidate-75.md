# 0.8.6 (75) — запуск записи и карточки магазина

Статус на 7 октября 2026: кандидат готовится после выпуска 0.8.5 (74).
Новый архив ещё не создан и Apple не загружен. Проверки ниже относятся
только к указанным результатам, а не к архиву предыдущей версии.

## Изменение приложения

В `SlideToStartView` исправлена маска внешнего жеста: в готовом состоянии
`.subviews` сохраняет drag вложенного бегунка. Прежняя `.none` отключала
и внешний обработчик, и жесты дочерних представлений.

Репорт: iPhone 15 Pro Max, iOS 17.6.1, слайдер неподвижен после обновления
TripTrack до 0.8.4; запуск через уведомление работает. Подробности и
ссылки на семантику Apple — в [разборе](../0.8.5/post-74-start-slider.md).

Порог свайпа, отказ при отсутствии GPS, действие «Всё равно начать»,
VoiceOver, логика записи, схема Core Data и серверный контракт не меняются.

## Карточки App Store

Подготовлены восемь карточек на русском и восемь на английском в выбранном
светлом оформлении: маршрут, атлас, попутчики, воспоминания, статистика,
гараж, публичная лента и достижения. Состав и проверки файлов — в
[документе карточек](../../store/screenshots-2026-10.md).
Факт подготовки файлов не означает их загрузку или отправку версии.

## Проверки

Тестовая конфигурация использует локальный недоступный API, чтобы UI-прогон
не взаимодействовал с production. Разрешённое окно работы со сборками
началось после 13:56 МСК 7 октября; физический iPhone не используется.

| Проверка | Результат |
| --- | --- |
| Версии приложения, Live Activity и Watch | В `project.yml` установлены 0.8.6 (75); проект сгенерирован. Watch по-прежнему не включён в схему выпуска. |
| Build for testing | Успешно; метаданные собранных приложения и Live Activity подтверждают 0.8.6 (75). |
| UI слайдера, iOS 18.6 | **3/3**, без пропусков: физический свайп с GPS запускает запись, без GPS показана причина, «Всё равно начать» запускает запись. |
| `StartRefusalTests`, iOS 18.6 | **3/3**, без ошибок и пропусков. |
| UI слайдера, iOS 26.5 | **3/3**, без ошибок и пропусков; те же три сценария на том же тестовом бинарнике. |
| iOS 17.6.1 | Runtime iOS 17 локально отсутствует; проверка на этой версии ещё не выполнена. |
| Release-архив и его проверка | Не выполнены. |
| Загрузка, обработка и App Review | Не выполнены. |

Тест со включённым GPS должен завершиться без `XCTSkip`: отсутствие
геопозиции и пропуск не подтверждают исправность обычного свайпа.
Приватные журналы и результаты сохраняются в `build-75-verification/`
личного каталога выката. Исходный commit и манифест архива фиксируются
после завершения проверок, до создания Release-архива.

Проверки выполнены 7 октября в 15:12–15:17 МСК на двух отдельных
симуляторах, которые после прогона выключены. Подтверждения:
`slider-ios18.xcresult`, `slider-ios26.xcresult`, их JSON-сводки и
`targeted-tests-summary.json`. Полный unit-набор повторно не запускался:
изменение приложения затрагивает только маршрутизацию жестов слайдера.

Успех на iOS 18.6 и 26.5 подтверждает проверенные сценарии, но не заменяет
проверку на iPhone с iOS 17.6.1 из исходного репорта. Короткий свайп,
переход ожидание GPS → готовность без ухода с экрана, геолокация с отказом
и VoiceOver остаются отдельными проверками из разбора.
