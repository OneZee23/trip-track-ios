# 0.8.7 (76)

Статус: подготовка, не опубликовано. Ветка `release/0.8.7`.

## Изменения

First-party opt-in счётчики локальной записи (`ProductAnalytics`). Включение
в «Настройки → Приватность», по умолчанию off. Без привязки к аккаунту,
облачной библиотеке и рекламным сервисам. Нового SDK нет.

Передаётся случайный код периода согласия, ревизия, дни UTC согласия/доставки/
первых двух локальных сохранений, признак существующей локальной библиотеки,
количество стартов/сохранений/ошибок/открытий Атласа и три интервала времени
локального завершения. Сервер хранит SHA-256 кода. Нет координат, расстояний,
маршрутов, названий, фото, заметок, машины или account/trip ID.

Счётчики начинают работу после согласия; первый/второй означает после согласия,
а не за всю жизнь пользователя. Локальная библиотека могла содержать импорт
или демо. Короткие отброшенные записи исключены, сохранённые черновики входят.
Позднее удаление поездки счётчик не уменьшает. Atlas opens — появления экрана,
не исследованные дороги. Время — синхронное завершение с расчётом статистики,
preview и чтением результата, а не только SQL и не облачный upload.

Состояние ограничено одним снимком счётчиков. ID активной записи хранится
только локально, чтобы восстановление процесса не теряло связь старта/финиша.
Повторные отправки и старые ревизии идемпотентны. Отключение очищает локальный
снимок и запрашивает удаление; серверный tombstone блокирует поздние upload.
Неактивные записи и tombstones удаляются через 90 дней. Согласие действует
до отключения; повторное включение создаёт новый код. Debug не отправляет
аналитику; тесты используют URLProtocol без production-запросов.

## Метрики и ограничения

`scripts/local-usage-report.cjs` в backend выдаёт только агрегаты по периоду
согласия и наличию старой библиотеки. Opt-in выборка, не вся аудитория;
нет cross-device дедупликации, D7 retention и маркетинговой атрибуции.
Офлайн-счётчики задерживаются; отзыв согласия убирает предыдущие данные.
