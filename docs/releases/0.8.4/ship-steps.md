Вместе с флагом удалён его сторож —

```bash

  -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 16' \
```

Полный `xcodebuild test` без `-only-testing` вешается на UI-таргете — гонять
UI-туры по одному и только когда они нужны.

Loopback API применяется только к тестам: фоновые общие сервисы не должны
обращаться к рабочему API во время unit-прогона. Release собирать без этого
override; production URL проверен в готовом архиве.

## ШАГ 4. Пуш и тег

Аннотированный тег **`v0.8.4` создан на `e2967dce`** — коммите исходников
проверенного архива 73. Его push в `origin` подтверждён 6 октября.
Повторно создавать или
переносить тег не нужно. Текущий HEAD содержит невыпущенные исправления;
помечать его как исходники 73 нельзя.

Сверка ссылки и публикация выполняются отдельно:

```bash
git rev-parse 'v0.8.4^{commit}'
git rev-parse e2967dce
git push -u origin release/0.8.4
git push origin v0.8.4
```

Перед пушем — проверка на секреты, как всегда в публичной репе:

```bash
git grep -nE 'ssh [a-z]+@|[0-9]{1,3}(\.[0-9]{1,3}){3}|BEGIN [A-Z ]*PRIVATE KEY'
```

И помнить: `git push --mirror` в этой репе делать нельзя — он вытолкнет
служебные `refs/t3/`.
