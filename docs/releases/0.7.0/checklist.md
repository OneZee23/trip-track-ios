# 0.7.0 «Атлас: настоящий туман» — что нажать

Код на ветках, тесты зелёные. Порядок тот же, что в 0.6.6, 0.6.7 и 0.6.8:
**бэкенд раньше сабмита**, тексты стора во все локали карточки, рейтинг 13+ уже
стоит.

Два отличия этого релиза от прошлых.

**Первое: половина версии видна только на настоящей дороге.** Прорезь у машины
на записи, плавность тумана в щипке и броске, память на долгой поездке — ни
тестом, ни симулятором это не проверяется. Пункты §2 отмечены соответственно.

**Второе: первый авторский секрет включается РУКАМИ и последним.** «Знак
Комсомольского» вставляется в базу выключенным (`is_active = false`), и до тех
пор, пока владелец не напишет историю, он таким и остаётся: в строке стоит
буквальная заглушка `<<ОЖИДАЕТ ТЕКСТ ВЛАДЕЛЬЦА>>`. Выкатка релиза от этого не
зависит — секретов в каталоге просто нет, и приложение работает на загадках и
вехах.

## 1. Бэкенд — сначала он

Деплой идёт с `master`: CI (`.gitlab-ci.yml`) выкатывает каждый пуш туда.
Поэтому всё, что должно стоять на проде ДО первого запроса клиента, ставится ДО
пуша.

- [ ] **`SECRETS_SALT` в `.env` прода — ПЕРВЫМ ДЕЛОМ, до пуша.** Значение —
      `tt-secrets-v1`, ровно то же, что в `.env.example` и в бандле телефона.
      Соль публична сознательно (`docs/secrets.md`, раздел «Соль»): её работа —
      обесценить готовые радужные таблицы, а координату прячет усечение хеша до
      четырёх байт. Разойтись двум значениям нельзя: на другой соли ни один
      секрет не совпадёт ни у кого, и заметить это можно будет только по
      молчанию.
- [ ] **Замороженный вектор соли сходится.** `truncatedHash("tt-secrets-v1",
      "ubcr4xk") = 2566105652` — если после выкатки каталог отдаёт другие числа,
      соль на проде не та.
- [ ] **Слить `release/0.7.0` в `master` и запушить** (`5eee54c..HEAD`).
      Одиннадцать коммитов: пуш админу о регистрации, таблицы `secret` /
      `secret_find`, `GET /secrets/catalog`, `POST /secrets/reveal`,
      `POST /secrets/forget-all`, поле `finds` в публичном профиле и секция
      `discoveries` в `/sync/pull`.
- [ ] **Обе миграции guarded**: `1790000000000-AddAdminNewAccountPush`
      (`account.is_admin`, `account.notify_new_accounts`) и
      `1791000000000-AddSecrets` (таблицы секретов) — `ADD COLUMN IF NOT
      EXISTS`, `CREATE TABLE IF NOT EXISTS`. Прод живёт на `DB_SYNC=true` и
      создаёт то же самое из сущностей; миграции здесь дублирующая страховка.
      После выкатки посмотреть лог старта: ни одного `QueryFailedError`.
- [ ] **Смоук по живому проду.** Маршруты объявлены через `GetApiEntry` /
      `PostApiEntry`, ответ всегда в конверте `{"status":"ok","payload":{…}}` —
      голого объекта не будет:
      ```
      curl -s 'https://api.trip-track.app/secrets/catalog?version=' | jq .payload
      ```
      Ждём `version` и пустой (или почти пустой) список секретов:
      `is_active = false` у Комсомольского значит, что его тут быть НЕ должно.
      **Ошибка приезжает HTTP-кодом 200 с телом `{"status":"error","code":"…"}`**
      — не принимать 200 за поломку маршрута.
- [ ] **Флаг админа себе.** Тумблер «Новые пользователи» в уведомлениях виден
      только аккаунту с `is_admin`, и эндпоинта для его выставления нет
      сознательно — только рука в базе:
      ```sql
      SELECT id, email, created_at FROM account ORDER BY created_at LIMIT 10;
      UPDATE account SET is_admin = true WHERE id = '<uuid>';
      ```
      Свой аккаунт — самый ранний в этом списке. После этого переоткрыть
      «Уведомления» в приложении: карточка «Админ» появится.
- [ ] **Вставить секрет Комсомольского выключенным.**
      `psql -f docs/secrets/komsomolsky.sql` (или тем же содержимым через
      `npm run typeorm`). В файле `is_active = false`, тринадцать заголовков и
      `story` ru/en с буквальной заглушкой `<<ОЖИДАЕТ ТЕКСТ ВЛАДЕЛЬЦА>>` —
      именно буквальной, чтобы `grep` нашёл её и в базе, и в репозитории.
- [ ] **Проверить, что каталог его НЕ отдаёт.** Тот же `curl` по
      `/secrets/catalog`: `komsomolsky` в списке быть не должно. Если он там —
      `is_active` не выставился, и секрет уехал к людям без истории.

### Активация секрета — ОТДЕЛЬНЫЙ шаг, после текста владельца

Это не часть выкатки и не часть сабмита. Делать тогда, когда история написана;
до тех пор релиз живёт без секретов, и это нормальное состояние.

- [ ] **Владелец пишет историю** «Знака Комсомольского» — хотя бы `ru` и `en`
      (`en` обязателен: сервер берёт `title[язык] ?? title.en`, запасного
      английского на уровне базы нет, и пропущенный язык вернётся как `null`).
- [ ] **Вписать текст и включить — одним `UPDATE`, и обязательно с
      `updated_at`:**
      ```sql
      UPDATE secret
         SET story = '{"ru":"…","en":"…"}'::jsonb,
             is_active = true,
             updated_at = now()
       WHERE id = 'komsomolsky';
      ```
      **`updated_at = now()` несёт каждый ручной `UPDATE`.** `version` каталога
      считается из пар `id:updated_at` активных секретов, клиент качает список
      только на смене версии, а колонка сама обновляется ТОЛЬКО через TypeORM —
      мимо него правка останется невидимой для телефонов навсегда
      (`docs/secrets.md`, раздел «Любой ручной UPDATE»).
- [ ] **Проехать и раскрыть.** Каталог отдал хеши → проехать через район (или
      послать `POST /secrets/reveal` с `tripId` уже лежащей на сервере поездки,
      трек которой идёт через ячейки) → `verified: true`, правильные
      `title`/`story` на языке аккаунта, повторный вызов `foundAt` не двигает.
- [ ] **Скрытый значок.** После находки в гараже значков открывается
      `secret_komsomolsky` (категория `exploration`).

## 2. iOS — пальцем на телефоне

Автотесты закрывают правила и арифметику. Ниже — сведённые чек-листы волн 1b, 2
и 4: то, что видит только человек.

### 2.1 Туман и «Атлас»

- [ ] **Первый вход в «Атлас» после холодного старта.** Первый кадр обязан быть
      ровным туманом, а не картой Apple. Это чинил фикс-раунд волны 1b, и
      промах здесь показывает миру всё, чего человек не видел.
- [ ] **Щипок внутрь и наружу до предела, бросок с инерцией.** Туман с
      коридорами едет вместе с картой: чёрных прямоугольников нет, подписи
      регионов, точки городов и пины на месте. За краем растра — ровный туман, а
      не карта Apple.
- [ ] **Поворот двумя пальцами есть, наклона нет.** Наклон отключён
      сознательно — в перспективе коридор отъезжал бы от дороги под ним. При
      повороте туман не отстаёт и углы экрана не оголяются.
- [ ] **Экран поездки: карта-герой → «раскрыть» → реплей.** Маршрут и машинка
      ВИДНЫ поверх тумана, и туман там — «как мир выглядел на ту дату».
- [ ] **Живая запись, реальный выезд.** Прорезь у машины растёт плавно и стоит
      на земле, а не на экране; карта под пальцем не дёргается; на перекрёстке в
      режиме «по курсу» экран не гаснет. **Единственное место, которое нельзя
      проверить ни тестом, ни симулятором.**
- [ ] **Долгая запись (час и больше) с открытым экраном.** Смотреть память в
      Xcode: ожидание — до ~37 МБ на растры вуали, кратковременно до ~55 МБ в
      момент подмены. Ощутимо больше или предупреждения памяти — дешёвая правка
      `renderScale` для вращаемых карт.
- [ ] **Телефон, где библиотека приехала синком** (второе устройство или
      переустановка): «Атлас» обязан открыться в ту же сессию, без перезапуска
      — это проверка двери пула.
- [ ] **Чужая поездка и чужое путешествие.** Карта ровно такая, какой была до
      0.7.0: вуали там нет вовсе.

### 2.2 Находки

- [ ] **Увидеть круг подсказки.** «Атлас», отдалить до края: не больше трёх
      пунктирных кругов с «?» и одной строкой, ближайших к уже открытому. Круги
      5–30 км, точка внутри никогда не в центре. Ни одного — либо всё рядом
      решено, либо подсказки не доехали.
- [ ] **Решить загадку.** Ближайшие к Краснодару точки бандла:

      | тип | имя | от центра | координата | засчитывается |
      |---|---|---|---|---|
      | border | (без имени) | **4.6 км** | 45.01686, 39.02760 | 300 м |
      | pass | Pshadskiy | 76.1 км | 44.46682, 38.43837 | 300 м |
      | lighthouse | (без имени) | 83.9 км | 44.30548, 38.70588 | 600 м |
      | lighthouse | Gelendzhikskiy mayak | 90.7 км | 44.55021, 38.05017 | 600 м |
      | pass | Agoyskiy pereval | 100.6 км | 44.13188, 39.04739 | 300 м |

      Самый дешёвый прогон — первая строка: переезд через Кубань в Адыгею,
      пятнадцать минут по городу.
- [ ] **На ходу — тишина.** Пока идёт запись: ни звука, ни вибрации, ни
      баннера «рядом секрет». Это правило безопасности, а не вкуса, и проверять
      его надо именно на той поездке, которая что-то найдёт.
- [ ] **Блок «Открыто» на экране итогов.** Между плитками и наградами: строка
      «N км нового пути · 1 загадка», ряд печатей, и туман **выгорает с
      карты-героя** по свежему пути (~0.7 с; при «Уменьшении движения» —
      кроссфейд). Ничего не нашлось — блока быть не должно вовсе, ни каркаса,
      ни «ищем».
- [ ] **Тап по блоку** уводит на «Атлас» прямо к печати. Набранное в описании
      поездки при этом не пропадает.
- [ ] **Профиль → значки**: после первой загадки открывается скрытый «Первая
      загадка». Опыта находки не дают — так и задумано.
- [ ] **Отдалить до страны**: печати кластеризуются, цвет кластера — по
      большинству.

### 2.3 Журнал, карточки, постер

- [ ] **Лист «Атласа» вверх**: три группы, ни одного процента и ни одного
      кольца покрытия. Проверить и библиотеку с ОДНИМ регионом — лист должен
      открываться журналом, а не сразу карточкой региона.
- [ ] **Тап по печати в сетке** → карточка листом ПОВЕРХ журнала; закрыть —
      вернуться в ту же сетку, не на карту. «На карте» → камера к печати, и в
      панели карты у той же карточки кнопки «На карте» уже нет.
- [ ] **Карточка загадки**: под пунктиром живая тёмная мини-карта, без точки
      внутри. Серая миллиметровка с «Maps» — это сеть, а не сбой телефона.
- [ ] **«Поделиться» со свёрнутого листа**: пилюля «Готовим снимок…», потом
      системный лист с КАРТИНКОЙ и текстом. На картинке: коридоры на своих
      дорогах, печати на своих местах, **ни одного круга нерешённой загадки**.
      Отдельно в самолётном режиме — уезжает один текст, без пустой сетки.
- [ ] **Cloud Sync выключен** → на карточке секрета нет ни строки «нашли N», ни
      намёка на счётчик. Ноль вместо счётчика был бы неправдой.
- [ ] **Немецкий и турецкий** на карточке и в журнале (самые длинные строки):
      подпись постера ужимается сама, но число не должно уехать.
- [ ] **Счётные слова** в «нашли N человек» и в списке регионов: русский и
      украинский — три формы, польский — своя, индонезийский — без
      множественного. Проверить на 1, 2 и 5.

## 3. Сабмит

1. **Версию поднимать НЕ нужно** — `project.yml` уже `MARKETING_VERSION:
   "0.7.0"`, `CURRENT_PROJECT_VERSION: "61"`. Проверить, что это стоит во ВСЕХ
   трёх блоках (приложение, расширение, виджет), и запустить `xcodegen
   generate`.
2. **`.xccurrentversion` = `TripTrack v18`.** Версий модели в релизе три новых,
   поэтому `xcodegen generate` — **ДВАЖДЫ**: первый прогон переписывает файл на
   прежнюю версию, второй уважает его. Без проверки соберётся v15, а ошибка
   будет выглядеть как «сущность не найдена».
3. **Sentry**: `SENTRY_DSN[config=Release]` в `Local.xcconfig` на месте (файл
   вне гита, на другой машине пуст). После архива:
   `/usr/libexec/PlistBuddy -c "Print :SENTRY_DSN" <архив>/…/TripTrack.app/Info.plist`
   — должен вернуть DSN, а не пустую строку. Пустой ключ с 0.6.6 пишет `notice`
   в системный лог при запуске: посмотреть его дешевле, чем архив.
4. Xcode → Product → Archive → Distribute → App Store Connect.
5. **«What's New» во все двенадцать локалей** карточки из `app-store.md` — не
   тринадцать языков приложения. Слот «Finnish» держит ФИЛИППИНСКИЙ текст,
   казахского в карточке нет вовсе. Сабмит 0.6.2 отклонили ровно за одну
   пропущенную локаль.
6. **Notes для ревьюера** — блок v0.7.0 из `docs/releases/app-review-notes.md`.
   Отдельной учётки не заводим: вход через Sign in with Apple собственным Apple
   ID ревьюера, и это в заметках сказано.
7. **Дату в CHANGELOG**: `## [0.7.0] -- в работе` → дата отправки.
8. **App Privacy не трогать** — новых типов данных нет (`app-store.md` §3).
   `PrivacyInfo.xcprivacy` остаётся как есть.

## 5. Что осталось ЗА версией (решения, не долг)

- **Бандл загадок собран частично, и это записано, а не спрятано.**
  `Tools/build_secrets.py` ходит в публичный Overpass, и 16 сен 2026 тот весь
  прогон отвечал 429/504: в `Riddles.json` уехали перевалы, погранпосты, маяки,
  паромы и плотины (1 028 точек), а смотровые, обсерватории, мосты, дороги в
  море, крайние точки, центры и трипойнты — нет. Ни одной точки не выдумано:
  тип без данных — пустой тип, не заглушка. Повторный запуск скрипта добирает
  недостающее и обновляет бандл в следующей версии.
- **«Км нового пути за 30 дней» в журнале нет.** Слой открытого хранит
  СОСТОЯНИЕ, а не историю, и «за месяц» пришлось бы считать разницей по всей
  библиотеке — сотни тысяч точек ради одной строки. Заведётся, когда дельта
  начнёт где-то храниться.
- **Секрет, найденный только на втором телефоне, на этом не появится** — строка
  пула не везёт координату. Дыра контракта, известная и записанная; закрывается
  полем `lat`/`lon` в строке пула, то есть правкой обеих сторон.
- **Находки не дают опыта и не двигают уровень машины.** Это дневник, а не
  награда; значок за первую загадку — единственное исключение и он скрытый.
- **Своих находок в своём профиле нет** — они в журнале. Дублировать одно и то
  же в двух местах не стали.
