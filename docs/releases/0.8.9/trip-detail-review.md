# Экран поездки: разбор и правки

11 октября 2026. Ветка `work/web-manual-sync-089`. Не выпущено.

Разбор по скиллам KK (kk-1337, kk-interface, kk-typography, kk-look,
kk-motion) с тремя редакциями. Вторая сверила первую с прежними решениями
владельца и отозвала половину предложений: цветные плитки — канон 0.6.0 и
общий язык с финишем, пустые блоки — точки входа (описание с пунктиром —
0.5.8, по отзыву), обсуждение у своей поездки есть всегда. Осталось то, что
нарушает уже принятые правила. Владелец согласовал все пункты 11 октября.

## Решения

- Повтор «В движении / Без движения» (плитки и полоса) оставлен: плитка —
  число, полоса — пропорция, между ними больше экрана прокрутки.
- Числа плиток не масштабируются — как статистика в «Я» (0.8.8).

## Проверено

Симулятор iPhone 16, iOS 18.6. Полный `TripTrackTests`: 2901 тест, 0 падений.
UI: `TripDetailTopBarScrollTests`, `TripDetailTapTargetsTests` — оба красные на
коде до правки. Кадры до и после (свои, вписанная, чужая поездка, тёмная
тема, AX L, AX XXXL) — `~/Desktop/TripTrack-Reviews/2026-10-10-trip-detail/`
вне репозитория.

Ловушка теста: `-selectedTabV2` в аргументах запуска — домен UserDefaults с
наивысшим приоритетом, и `@AppStorage` вкладки из него не выйдет. Тест,
которому нужен переход на другую вкладку, жмёт вкладку сам.
