# DRIVE2 в 0.9.1: только ссылка, без бренда и без данных

Решение владельца 22 октября 2026: человек привязывает к своей машине ссылку на
её бортжурнал в DRIVE2, а кнопка на странице машины открывает его. Договора с
DRIVE2 у нас нет, поэтому DRIVE2 для приложения — просто внешний сайт, как
любая соцсеть, на которую человек оставил ссылку. Ниже — что говорят их правила
и что из этого следует для кода. Проверено 22 октября 2026.

## Что говорят их документы

- **Пользовательское соглашение** (`drive2.ru/agreement/`, без даты редакции;
  меняется без уведомления, новая редакция действует через 3 дня).
  - п. 4.10 — запрещено воспроизводить, копировать, продавать и использовать
    в коммерческих целях любые части сайта без письменного разрешения
    администрации;
  - п. 4.12 — запрещены искусственные методы, имитирующие действия
    пользователя;
  - п. 4.6 — запрещён сбор и хранение персональных данных других лиц и
    нарушение работы сайта;
  - п. 6.1–6.3 — ПО, дизайн и торговые марки принадлежат администрации;
    запрещено использовать материалы сайта для обучения ИИ.
  - Отдельного пункта о ссылках на сайт нет; ссылка на первоисточник
    упоминается как нормальная практика (п. 4.2).
- **Товарный знак.** «DRIVE2.RU» (№ 921534) и «DRIVE2.RU СООБЩЕСТВО МАШИН И
  ЛЮДЕЙ» (№ 566418) зарегистрированы за ООО «Драйв». Право использовать знак
  оферта для компаний (раздел 8) даёт только своим заказчикам и только на
  время договора. Публичных правил использования логотипа сторонними сайтами
  и приложениями нет; страница «Символика» — про наклейки для владельцев машин.
  Вопросы о бренде — `support@drive2.ru`.
- **Открытого API нет** (их команда на форуме); универсальные ссылки есть: файл
  `/.well-known/apple-app-site-association` на `www.drive2.ru`, `drive2.ru` и
  `drive2.com` объявляет пути `/r/*` (машина), `/l/*` (запись бортжурнала),
  `/users/*` за приложением `ru.drive2.iosapp`.

## Что из этого следует для кода (правила)

1. **Ни логотипа, ни фирменного цвета, ни шрифта DRIVE2.** Строка рисуется
   нашими средствами: нейтральный значок стрелки `arrow.up.right` в нашей
   плашке, наш акцент. Слово «DRIVE2» стоит только как название сайта, куда
   ведёт ссылка («Бортжурнал на DRIVE2») — так же, как пишут адрес.
2. **Ничего не скачиваем с их сайта.** Ни приложение, ни сервер не открывают
   привязанную ссылку: не берут `og:title`/`og:image`, не проверяют, жива ли
   страница, не показывают превью. Ссылку человек вставляет сам, мы разбираем
   только СТРОКУ (`Drive2Link`) и храним её. Иначе это копирование частей
   сайта (п. 4.10) и автоматический доступ (п. 4.12).
3. **Открываем как обычную ссылку** — `openURL`. Стоит их приложение — система
   откроет машину в нём (универсальные ссылки), нет — сайт в Safari. Своей
   схемы, `LSApplicationQueriesSchemes` и встроенного браузера нет.
4. **Принимаем только страницу машины** (`/r/<марка>/<модель>/<id>`) на
   доменах drive2.ru / drive2.com. Любая другая ссылка отклоняется — иначе
   чужие профили стали бы доской для спама. Та же проверка на сервере.
5. **Не называем это «интеграцией с DRIVE2»** ни в приложении, ни в описании
   App Store, ни в рекламе: партнёрства нет, и слова о нём читались бы как
   использование их знака без разрешения. Пишем «ссылка на бортжурнал».
6. Всё, что больше ссылки (кнопка «Опубликовать в DRIVE2», их значок, данные
   машины оттуда), — только по договору через `drive2.ru/promo/`.
