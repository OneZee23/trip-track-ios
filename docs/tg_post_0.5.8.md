🚗 **TripTrack 0.5.8 — хотфикс по вашему фидбэку**

Снова собрал репорты от самого активного подписчика (спасибо! 🙌) и закрыл всё по списку. А ещё — фича прямо по вашей просьбе из чата.

**🗺 Новое: поездки на глобусе**
В профиле появился тумблер — показывать ли свои **публичные** поездки на глобусе на сайте. По умолчанию выключено, приватные не попадают туда никогда, маршрут анонимизируется (концы обрезаются). Да, это та самая идея 😉

**🛣 Карта при записи больше не мигает**
Оранжевая линия маршрута перестала моргать в движении — рендер стал плавным.

**⏱ Честный спидометр на остановке**
На светофоре больше не «висит» 16 км/ч — показывает 0, как и должно.

**🚀 Старт без зависаний**
Экран «Готов к поездке» больше не застревает в бесконечной загрузке.

**📲 Лента сразу на месте**
Открываешь приложение — лента уже загружена, без ручного потягивания вниз.

**🖼 Фото в полном качестве**
Оригиналы теперь грузятся на любой сети, а не только по Wi-Fi.

**✍️ Заметки на виду**
Описание поездки больше не теряется под статистикой — добавить стало проще.

Качайте, тестируйте и пишите ещё — фидбэк в этот раз снова топ 🙏
