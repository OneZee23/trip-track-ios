# Metal-туман на «Атласе» (0.8.0) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** довести одобренный спайк `da0ce5ad` (Metal-слой тумана на «Атласе») до продакшена, не изменив картинку: покой без тиков, вырез под подписью Apple, постер тем же кодом, откат, тесты, документация.

**Architecture:** `FogMetalVeil` (`MTKView`) рисует туман каждый кадр жеста по матрице карты: покрытие коридоров капсулами в `r8Unorm` с blend `max`, композит ровной мглы с премультиплицированной альфой. Данные — `FogMesh` из `RevealedLayer` (куски 32768 map points, `Float32`-смещения). Слой садится рядом с растровой вуалью (`VeilSeat`), которая на «Атласе» остаётся только хостом жилки (`vectorOnly`).

**Tech Stack:** Swift 5.9, MapKit, Metal/MetalKit, XCTest. Симулятор `BA1BECF1-1C7D-43A5-A1B1-20D05D602F73`, устройство `C539C647-8F2C-5681-9330-39CD44F67637`.

**Spec:** `docs/superpowers/specs/2026-09-22-080-fog-metal-design.md` — §3 «Инварианты картинки» обязателен для КАЖДОЙ задачи.

- `Local.xcconfig`, `Info.plist`, `project.yml` не трогать. После добавления/удаления файлов — `xcodegen generate` (один раз; модели CoreData нет).
