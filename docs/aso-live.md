## ENGLISH (U.S.) — главная локаль

### Сейчас

```
Name:      TripTrack - Road Journal            24/30
Subtitle:  Automatic trip diary & tracker      30/30
Keywords:  road,trip,tracker,driving,diary,fog,war,exploration,map,car,route,recorder,GPS,journal,strava,travel
```

**Что не так с ключевыми словами.** Apple индексирует название, подзаголовок и ключевые
слова как один пул, поэтому повтор — это выброшенные символы:

- `road`, `journal` — уже в названии
- `trip`, `tracker`, `diary` — уже в подзаголовке
- вместе это **32 символа из 100**
- `strava` — **чужой товарный знак**, Apple такое снимает, а может и отклонить обновление
- `war`, `fog` — «fog of war», разрезанный запятой на два мёртвых токена; по слову «war»
  приложение для водителей не ищет никто
- `exploration` — 11 символов при почти нулевом объёме поиска
- `recorder` — дублирует `tracker` из подзаголовка

Итого впустую или с риском — около **половины поля**.

### Предлагается в 0.6.1

Название и подзаголовок **не трогать** — они хорошие. Заменить только ключевые слова:

```
mileage,odometer,speedometer,logbook,driving,car,motorcycle,route,gps,map,travel,commute,logger,fuel
```

Ровно 100 символов. Ни одного слова из названия и подзаголовка, ни одного чужого бренда,
ни одного мёртвого токена.

**Почему именно эти.** Английская карточка обслуживает два разных намерения сразу, и оба
подтверждены географией:

- **США, Австралия, Европа** — путешествие: `travel`, `route`, `map`, `driving`, `car`
- **Индонезия, Филиппины, Индия, Малайзия** — учёт: `mileage`, `odometer`, `logbook`,
  `commute`, `fuel`, и главное `motorcycle` — в ЮВА основной транспорт мотоцикл, а этого
  слова у нас не было вообще

`gps` + `logger` рядом дают Apple собрать фразу «gps logger» — реальный поисковый запрос.
`speedometer` законен: приложение показывает скорость вживую и максимальную по поездке.

### Промо-текст

`Promotional Text` **не индексируется поиском** и меняется **без релиза**, в любой момент.
Значит там место для красивой фразы, а в подзаголовке — для терминов. Сейчас всё наоборот
не сделано, подзаголовок хороший — просто помнить об этом на будущее.

## Новые локали карточки — по фактическим загрузкам

Порядок: **индонезийский (19) → немецкий (12) → французский (10)**. Турецкий (6) — потом.
Казахский и филиппинский — **не делать**: у Казахстана нет рынка, Филиппины сидят на
англоязычной витрине.

**Важно про описание:** Apple **не индексирует** описание для поиска. Индексируются только
название, подзаголовок и ключевые слова. Поэтому для новой локали в первую очередь нужны
эти три поля — они короткие. Описание влияет на конверсию, а не на охват, и его можно
взять из `docs/app-store-0.6.1.md` (для de/fr там уже написано) или временно оставить
английское.

**Оговорка:** ключевые слова ниже подобраны по смыслу и по тому, чем приложение является.
Носителем языка они не проверены. Перед заливкой стоит показать их человеку, который
реально говорит на языке — особенно индонезийский.

### Indonesian

```
Name:      TripTrack: Catatan Perjalanan       29/30
Subtitle:  Pelacak rute & jarak otomatis       29/30
Keywords:  odometer,kilometer,motor,mobil,berkendara,peta,gps,logger,bensin,harian,wisata,jalan,mudik,ojek,km
```

`catatan perjalanan` — «журнал поездок», основной термин. `motor` и `ojek` — мотоцикл и
мототакси, то, на чём там реально ездят. `mudik` — массовые поездки домой на праздники,
сезонный всплеск интереса именно к записи дороги. `bensin` — бензин, для учёта расхода.

### German

```
Name:      TripTrack: Fahrtenbuch              22/30
Subtitle:  Fahrten automatisch tracken         27/30
Keywords:  kilometerstand,tacho,motorrad,auto,route,gps,karte,reise,strecke,logbuch,spritverbrauch,km
```

`Fahrtenbuch` — самое сильное слово в этой локали: так по-немецки называется путевой
журнал, и его ищут в том числе для налогового учёта километража. `Kilometerstand` —
показания одометра, `Spritverbrauch` — расход топлива.

### French

```
Name:      TripTrack : Carnet de route         27/30
Subtitle:  Journal de trajets automatique      30/30
Keywords:  kilometrage,compteur,moto,voiture,trajet,gps,carte,voyage,itineraire,carburant,conduite,suivi
```

`Carnet de route` — идиоматичный «дорожный журнал». `Kilométrage` без диакритики
намеренно: в поле ключевых слов диакритика тратит символы, а Apple сопоставляет и так.

### Общее правило для всех новых локалей

**Название не должно быть голым `TripTrack`.** Это один непрозрачный токен, который
находят только те, кто уже знает бренд — то есть ровно не поисковый трафик. В каждой
локали за двоеточием должно стоять ключевое слово на её языке.

**Никаких многословных фраз в ключевых словах.** Apple сам склеивает одиночные слова во
фразы. `catatan perjalanan` через пробел покупает пробел; писать надо через запятую по
одному слову.

## Скриншоты

**Сейчас:** шесть кадров, только English (U.S.) 6.5″, **сделаны до редизайна 0.6.0**.
Используются для всех размеров и всех локализаций.

То есть с 16 августа в сторе лежит приложение, перерисованное целиком, с картинками
предыдущей версии. При воронке, состоящей на 100% из поиска, скриншоты — это и есть
конверсия, и она у нас 15%.

**Первые три кадра критичны** — только они показываются в листе установки.

Порядок под холодного человека из поиска:

1. что это вообще
2. как записывает — «нажал и забыл»
3. как выглядит поездка потом
4. карта всех дорог
5. попутчики
6. профиль, уровни, достижения
