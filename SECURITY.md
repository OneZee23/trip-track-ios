# Security

If you find a security or privacy problem in TripTrack — for example a way to
see someone else's private trips, home zone or account data — please do **not**
open a public issue. Write to **privacy@trip-track.app** instead, with the app
version and steps to reproduce. You will get a reply, and the fix will be
credited in the release notes if you wish.

The iOS app is open source; the server and website live in separate private
repositories, but reports about them are welcome at the same address.
