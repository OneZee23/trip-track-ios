# Customer Voice Log

**Назначение:** running document с цитатами реальных пользователей. Источник правды для копирайта, ICP, и onboarding decisions. Никаких пересказов — только **дословные** цитаты с источником и датой.

**Правило:** добавляй каждую цитату которую слышишь, читаешь в App Store review, видишь в комменте на Drive2/Reddit/HN. Не редактируй грамматику.

---

```
### YYYY-MM-DD — <Имя/Ник> (<источник>)

> "Дословная цитата"

**Контекст:** что обсуждалось

**Source URL:** <если есть>
**Action item:** что я с этим сделаю (если что-то)
```

### 2026-05-19 — DedMoped810 (Drive2, VW Taos)

> "Камеры: — Съезд с Южки на М4, — Подъём перед Адыгейском, — На повороте на Тахтамукай, — За заправкой Газпрома на выезде из Адыгейска, — Псекупс. Дальше до Саратовской поливай сколько влезет)))"

**Контекст:** комментарий-ответ под статьёй на Drive2 — человек по своей инициативе перечислил 5 камер на твоём конкретном маршруте.
**Категория:** ICP-сигнал. Это профиль **человека который знает свой маршрут наизусть**. TripTrack для такого = "способ задокументировать что я уже знаю". Совпадает с гипотезой ICP "повторяющиеся маршруты".
**Source URL:** Drive2.ru (TripTrack promotion post comments, май 2026)
**Action item:** Подумать о фиче "Notes/Markers on Route" — let user pin known waypoints (cameras, lookouts, friend's house). Это естественное расширение для нашего ICP. Месяц 2-3 backlog.

## Theme analysis (обновлять после каждых 5+ цитат)

### Май 2026 (на 4 цитаты)

**Pattern 1: ICP-валидация **частично подтверждена** (2/4 цитат)**
- Self-quote и DedMoped810 указывают на профиль "повторяющиеся маршруты, знаю их наизусть, хочу видеть паттерн"
- Слишком малая выборка — нужны W1 interviews для надёжного подтверждения

**Pattern 2: Drive2 — wrong acquisition channel (1/4 негативная)**
- HoodooCH ясно показал mismatch — car-enthusiast aesthetic не совпадает с TripTrack value
- Drive2 = research-only канал, не acquisition

**Pattern 3: Install friction существует (1/4)**
- Elo2sti не может скачать — причина неизвестна, ждём ответа
- Если 2+ таких в месяце 1 → серьёзный issue (FAQ или Android)
